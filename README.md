# Morena Dlamini

Software engineer at Booyco Electronics, Johannesburg — a mining-safety company. I build
the internal systems the business runs on, for people who are not developers and cannot
wait for a fix.

| Shipped | For whom | What it does |
|---|---|---|
| Field-service application for Windows tablets | Field technicians, on site | Conduct certificates of compliance and service reports where the work happens. NFC tag scanning identifies the equipment being inspected, so the record starts from what is physically in front of the technician rather than what was typed |
| Leave-data pipeline, Sage → Firebase | Payroll and the internal clock-in system | Approved leave flows into clocking-in without anyone re-keying it |
| Field-work web platform *(contributor)* | Managers | Shows the COC and service work being done on site as it comes in |
| Internal platform with single sign-on *(in progress)* | The whole company | One login across several internal applications |

None of it is at scale, and I say so. What it is: real users, real consequences, and the
lessons that only come from that — data crossing a system boundary is where things break;
a form that becomes a legal document needs explicit states; single sign-on is where
authentication stops being a library and becomes a design.

**[worked-examples](https://github.com/MorenaDlamini/worked-examples)** is the other half:
each topic I study becomes a module — a written lesson, failing tests, my solutions, a
spoken answer — and CI runs every module on every push.
[`CONTRIBUTING.md`](https://github.com/MorenaDlamini/worked-examples/blob/master/CONTRIBUTING.md)
is the bar; [`NON-CLAIMS.md`](https://github.com/MorenaDlamini/worked-examples/blob/master/NON-CLAIMS.md)
is what it refuses to claim.

**Direction.** Data infrastructure, API design, and the security around both — the overlap
rather than either alone. The work above already leans that way;
[`CURRICULUM.md`](https://github.com/MorenaDlamini/worked-examples/blob/master/CURRICULUM.md)
names the roles it is aimed at and the exit test for every phase. It carries no dates.
